# SPEED TECHS — Landing Page Prototype

A responsive, single-page concept for SPEED TECHS, aimed at a Manchester (UK) vehicle technology audience.

## Preview

Open `index.html` in a modern browser. The prototype uses local SVG brand artwork and a custom vector vehicle illustration in `assets/`.

## Included

- Responsive navigation for desktop and mobile
- Original SPEED TECHS logo and favicon
- Original vector hero vehicle visual
- Service cards for all four requested service areas
- About, process, customer feedback placeholder, quote form and footer sections
- Front-end form validation and preview-only feedback state
- No fabricated customer reviews, company address, telephone number, email address, awards or performance claims

## Before using this on a live website

1. Confirm the final business name and legal business/contact details, then add them to the footer and contact section.
2. Replace the WhatsApp placeholder link (currently points to the quote form) with the client's verified WhatsApp URL/number.
3. Connect the quote form to an approved email inbox, CRM or WordPress form plugin. The current form does **not** send or store submissions.
4. Add the client's genuine customer reviews only after receiving approval to publish them.
5. Add a privacy notice and any appropriate cookie information. The form currently includes a simple consent checkbox but is not a complete privacy solution.
6. Confirm the exact wording and lawful scope of mileage-related services with the client. The current copy is intentionally cautious: mileage correction is described only for a verified, evidenced fault; mileage blockers are not promoted for concealing or misrepresenting mileage.
7. Check the final page with the client's actual service area, hours, contact details, policies and approved images.

## Brand direction

- Midnight navy / charcoal: `#08111d`
- Electric cyan: `#45d2f4`
- Cool light background: `#f3f6f8`
- Display type: Space Grotesk (Google Fonts, with local sans-serif fallback)
- Body type: DM Sans (Google Fonts, with local sans-serif fallback)

## Files

- `index.html` — page content and structure
- `css/style.css` — styling and responsive breakpoints
- `js/main.js` — mobile navigation and quote-form preview behaviour
- `assets/speed-techs-logo.svg` — editable vector logo artwork
- `assets/hero-vehicle.svg` — editable vector hero illustration
- `assets/favicon.svg` — browser icon

This is a front-end prototype, not a complete production WordPress website. It does not include server-side form processing, a live WhatsApp destination, a CMS, analytics, or SEO/legal review.
